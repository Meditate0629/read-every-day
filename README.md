# Read Every Day

**每天读一点。** 一个不上传、不登录、数据只留在自己设备上的读书管理 App。

**[在线使用 →](https://meditate0629.github.io/read-every-day/)**

iPhone 用 **Safari** 打开上面的网址 → 分享 → **添加到主屏幕**，之后就像原生 App 一样全屏使用，断网也能打开。

---

## 它是什么

把「读什么、什么时候读、读了多少、读到了什么」放在一个地方：按年 / 月 / 日排读书计划，用计时器或番茄钟记录时间，边读边记笔记和摘录，到点提醒你，读完把笔记或书单导出成图片 / PDF 分享。

没有账号、没有服务器、没有统计上报。所有数据都存在浏览器的本地数据库里，关掉网络照样能用。

## 功能

| 模块 | 能做什么 |
|---|---|
| **首页** | 今日 / 本月 / 今年三张统计卡；快速备忘，一键转成笔记 |
| **计划** | 年 → 月 → 日三层计划；加书（想读 / 在读 / 读完 / 暂停）；月目标、年目标；电脑上拖拽排期，手机点选排期；书籍详情抽屉 |
| **笔记** | 双栏编辑（手机上列表 / 编辑两段式）；自动保存；摘录与正文分开；标签、搜索、最近删除（30 天内可恢复） |
| **计时** | 正计时 / 番茄钟；切页面不中断；意外关闭后回来会问要不要补记；结束时可顺手更新页码、写一条笔记；中断的番茄不计入番茄数 |
| **提醒** | 每天 / 每周 / 每月末 / 指定日期 / 读到某页，五类提醒；到点弹窗（开始计时 / 知道了 / 顺延）；错过的进收件箱补录 |
| **分享** | 笔记方图、长图，读书计划卡，A4 书单 / 笔记页；导出 PNG / PDF；三个模板；导出历史 |
| **设置** | 深浅色、字号、12 / 24 小时制、周起始日、番茄默认值、备份与恢复，以及**内置 19 项自检** |

全局：`Ctrl / ⌘ + K` 命令面板，可以直接搜书、搜笔记并跳转。

## 开始使用

### 直接在线用

<https://meditate0629.github.io/read-every-day/>

### 本地跑（改代码时）

纯静态站点，不需要安装依赖，也不需要构建：

```bash
npx serve .
# 或者
python -m http.server 8080
```

然后打开 <http://localhost:8080>。

> 直接双击 `index.html`（`file://`）也能打开，但浏览器在这种情况下不给用 IndexedDB，会自动降级到 localStorage（约 5 MB）。日常使用建议走 http。

## 数据与隐私

- 数据只存在**当前浏览器**的 IndexedDB 里（降级时是 localStorage）。
- 没有后端、没有账号、没有埋点；这个仓库只是静态文件。
- **换浏览器、清浏览器数据、换域名，数据都不会跟过去。** 设置页可以导出全部数据（JSON），换设备时导入即可；每天首次打开还会自动备份一份到下载文件夹。
- 提醒依赖页面开着，关掉页面就不会响；错过的会在下次打开时列出来。

## 技术实现

- **原生 HTML / CSS / JavaScript**，零依赖、零构建：一个 `index.html` 加若干经典脚本，没有框架也没有打包步骤。
- **PWA**：`manifest.webmanifest` + `sw.js`，加到主屏幕后全屏运行、离线可用（Service Worker 只在 https 下注册）。
- **存储降级**：IndexedDB 优先，被拒绝时自动退回 localStorage —— 功能一致，容量更小。
- **自己生成 PDF**：不引入任何库，画布绘制 → JPEG → 按 `DCTDecode` 写进 PDF。代价是 PDF 里的文字不能选中、不能搜索。
- **内置自检**：设置页可以一键跑 19 项本机检查（存储、备份、计时、提醒、导出等），改完代码用来回归。
- 电脑端和手机端共用同一套页面代码，靠断点和 `isPhone()` 切换布局与交互（手机上关掉拖拽，改成点选）。

## 目录

```
index.html              单页壳（侧边栏 / 底部标签栏 + #view）
app.css                 全部样式（深浅两套配色、字号变量）
manifest.webmanifest    PWA 清单
sw.js                   离线缓存
util.js                 日期、时长、下载、弹窗等公共函数
store.js                IndexedDB + localStorage 降级
data.js                 统计与进度口径
backup.js               导出 / 导入 / 每日自动备份
pdf.js                  零依赖 PDF 生成
share.js                分享图与 A4 页面绘制
timer.js                计时引擎（正计时 / 番茄 / 离线补记）
reminders.js            提醒计算与错过补录
pages*.js               各页面渲染
palette.js              Ctrl+K 命令面板
selftest.js             19 项自检
main.js                 启动、路由、主题、快捷键
```

> 仓库里的文件是**平铺的发布版**，直接对应线上站点。带子目录的源版本在本地维护，发布时拍平并改写引用。

## 已知限制

- 提醒只在页面开着时生效（没有后端推送）。
- PDF 里的文字是图片，不可选中、不可搜索。
- `file://` 兼容模式容量约 5 MB，并且和 http 模式的数据**互相独立**。
- 数据不跨设备同步 —— 这是设计目标，不是缺陷。
